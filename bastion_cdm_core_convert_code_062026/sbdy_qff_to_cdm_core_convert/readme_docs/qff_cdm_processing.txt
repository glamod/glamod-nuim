SUB-DAILY QFF TO CDM-CORE CONVERSION PROCESS
============================================

This document describes the workflow for converting sub-daily QFF data
to CDM-Core format on the bastion host.

-------------------------------------------------------------------------------

-------------------------------------------------------------------------------

SSH to the bastion server:

    ssh bastion
    ssh glamodproc.ichec.ie

Sub-daily QFF input directory:

-------------------------------------------------------------------------------
3. CHECK CURRENT PROCESSING STATUS
-------------------------------------------------------------------------------

Count output files:

    ls -1 | wc -l

Check system memory (important for parallel runs):

    free -h

-------------------------------------------------------------------------------
4. CREATE PROCESSING LISTS
-------------------------------------------------------------------------------

Generate shuffled station execution commands from QFF files and split into
six batches.

Each station becomes a full python command.

Example single station test:

    python3 hourly_qff_to_cdm_core_v3.py --station MYI0000WMKK

Batch list creation:

    find /ichec/work/glamod/land_project_workspace/data/level1/\
level1c_sub_daily_data_qff/release_8.1 \
        -maxdepth 1 \
        -type f \
        -name "*.qff.gz" \
        -printf "%f\n" \
        | sed 's/\.qff\.gz$//' \
        | sort \
        | shuf --random-source=<(yes 42) \
        | sed 's/^/python3 hourly_qff_to_cdm_core_v3.py --station /' \
        > all_sub_daily.txt

Split into 6 batches:

    split -d -n l/6 all_sub_daily.txt sbdy_ls

Rename files:

    for i in {0..5}; do
        mv sbdy_ls$(printf "%02d" "$i") sbdy_ls$((i+1)).txt
    done

Resulting files:

    sbdy_ls1.txt
    sbdy_ls2.txt
    sbdy_ls3.txt
    sbdy_ls4.txt
    sbdy_ls5.txt
    sbdy_ls6.txt

-------------------------------------------------------------------------------
7. BATCH PROCESSING USING TMUX + GNU PARALLEL
-------------------------------------------------------------------------------

IMPORTANT NOTE:
- Only run 3 jobs concurrently at a time (memory constraints)
- Run in two batches if needed

Recommended launcher:

    ./submit_hr_bash.sh

Each tmux session runs GNU parallel:

-------------------------------------------------------------------------------

Session: sbdy_1

    tmux new -s sbdy_1
    source /ichec/work/glamod/land_project_workspace/code/r8_202508/
           hourly/muenv/bin/activate
    parallel --jobs 30 < sbdy_1.txt
